## What is TalentPulse?

GTM and recruiting teams are flying blind on talent market shifts.
They manually search job boards, copy-paste into spreadsheets,
and still miss the signals hiding in plain sight across the web.

**TalentPulse** is an always-on AI hiring intelligence platform that
turns live LinkedIn hiring data into enterprise GTM intelligence —
in seconds, not hours.

> *"We scraped 16,611 live LinkedIn jobs using 15 Bright Data snapshots
> across USA and India. Claude autonomously detected NVIDIA added 129
> net new roles in one week. This is the intelligence GTM teams pay
> $30,000/year for — TalentPulse generates it in seconds."*

 * get_top_gtm_targets(top_n=5)     → NVIDIA #1, Capital One #2
 * find_hot_opportunities(score=80) → 2,429 hot jobs detected

## How to Run

```bash
# 1. Clone
git clone https://github.com/shriyutha/TalentPulse.git
cd TalentPulse

# 2. Install
pip install -r requirements.txt

# 3. Add API keys
cp .env.example .env
# Edit .env with your keys

# 4. Run notebook
jupyter notebook TalentPulse_WINNING.ipynb

# 5. Run Streamlit app
streamlit run streamlit_app.py
```
